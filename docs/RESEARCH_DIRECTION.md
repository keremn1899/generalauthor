# Ontology Author research direction

**Status:** working research note, not product specification.

Current product constraints are in [`FOUNDATIONS.md`](FOUNDATIONS.md). This
document records the hypotheses, decompositions, open questions, and
experimental sequence that emerged after the grain-traceability research
campaign. It deliberately distinguishes what has been demonstrated from what
is only a plausible theory.

The purpose of this document is to prevent two opposite failures:

1. losing useful ideas because they lived only in conversation; and
2. prematurely turning those ideas into product architecture.

## 1. Empirical starting point

The current research base supports a narrower claim than the long-term vision.

The grain work showed that capable agents can independently construct materially
different grounded Worlds from the same purpose and heterogeneous evidence,
while preserving substantially the same supported semantic consequences and
uncertainty boundaries.

Fresh consumers can use such Worlds without reopening native evidence. This
moves work from repeated source-specific parsing and semantic reconciliation
toward semantic schema discovery, querying, derivation, and task reasoning.

Important negative results matter equally:

- a World is not universally more accurate than RAW reasoning;
- token amortization was not demonstrated at the basic World-consumer layer;
- deterministic World context reduced token use unevenly;
- durable semantic computations generalized partially and reduced ad hoc query
  construction, but token benefit was representation-dependent;
- none of those experiments created pressure for a larger semantic kernel.

The demonstrated value today is therefore **semantic persistence and
programmability**, not universal accuracy dominance or universal efficiency.

## 2. Long-term thesis

A useful long-term formulation is:

> **Ontology Author provides a durable semantic medium through which intelligent
> agent workflows may make experience cumulative.**

An even more operational formulation is:

> **Ontology Author lets intelligent work leave behind grounded semantic
> structure for future intelligent work.**

The intelligence is primarily outside the kernel.

A capable agent may eventually:

```text
observe work
    ↓
identify consequential distinctions
    ↓
infer the current purpose
    ↓
anticipate likely future reuse
    ↓
incorporate human / institutional judgment
    ↓
notice counterexamples
    ↓
decide what deserves persistence
    ↓
discover / use / refine / create a World
    ↓
decide whether repeated semantic reasoning
should become ordinary deterministic software
```

Ontology Author gives selected semantic interpretation a durable,
computational, grounded form.

This loop is a hypothesis about agent workflows, not a requirement that the
installed product implement an autonomous lifecycle engine.

## 3. The deepest abstraction hypothesis

### H1 — Worlds are purpose-relative abstractions

A World is not a general model of reality. It is a purpose-relative abstraction
that preserves distinctions needed for a class of work.

The useful discrimination test is:

```text
If two situations are represented identically by a World,
could they require different correct outcomes for its purpose?
```

If yes, the World is too coarse.

This suggests that purpose is not merely a retrieval filter over a complete
knowledge base. Purpose participates in the conceptual carving itself.

### H2 — truth is not purpose-relative; representation is

Different Worlds may collapse or preserve different distinctions without
implying incompatible truths.

The support abstraction "Acme" may coexist with legal-purpose referents for
Acme UK Ltd and Acme US Inc. Shared evidence does not require shared
World-level identity.

### H3 — local closure is possible; global semantic closure is not

Given a declared purpose and available evidence, a World can ask whether every
currently required distinction is represented or explicitly unresolved.

The universe of future purposes cannot be closed because new purposes are
generated by contact with an open external world: regulations, incidents,
customers, litigation, new products, organizational changes, tools, and future
questions.

A useful consequence is:

> **A World should be able to finish. The possible set of Worlds never does.**

## 4. The open-objective problem

There is a deeper reason a single final ontology is impossible in the general
case.

Let evidence be `E`, purpose/task family be `P`, and a World be an abstraction:

```text
W = φ_P(E)
```

The World is sufficient for a task family when every task-relevant outcome can
be recovered from `W`.

If every conceivable future task must remain answerable, then any distinction
that the abstraction removes can be made relevant by some future task.

Therefore the only representation guaranteed to be sufficient for every
possible future purpose is effectively one that discards nothing.

That is no longer useful abstraction.

This yields the long-term framing:

> **The hard problem is online abstraction selection under an unknown future
> distribution of purposes.**

Perfection is not merely difficult. A globally final target is not well-defined.

## 5. Refine vs create decomposes into smaller problems

"Refine an existing World or create another one?" initially looked like one of
the hardest problems. It can be decomposed.

### 5.1 Discrimination

What distinction does the current task require that the current abstraction
does not preserve?

This can often be observed through:

- different required outcomes from situations represented identically;
- user correction;
- repeated raw-evidence fallback;
- repeated manual semantic joins;
- query ambiguity;
- a previously hidden category distinction becoming consequential.

This is the most objective part.

### 5.2 Purpose membership

Does the new discrimination belong to the existing class of work?

This is harder. Natural-language purposes describe fuzzy, overlapping task
families, and use may reveal that the original purpose was underspecified.

### 5.3 Semantic modularity / factorization

Even if a new requirement is different in purpose, it is not logically
necessary to create a different World. One World could always be broadened.

Multiple Worlds are therefore partly a factorization strategy that preserves
the ability of each purpose-relative abstraction to ignore irrelevant
distinctions.

There may be no unique globally correct decomposition, just as there is no
unique globally correct software modularization.

This is encouraging because perfect factoring is unnecessary if Worlds are
cheap to reconstruct and imperfect organization is recoverable.

### Working bias

When uncertain, unnecessary duplication may be safer than premature semantic
unification because the former creates selection/maintenance overhead while the
latter creates conceptual coupling and universal-ontology drift.

This is a hypothesis, not yet a product rule.

## 6. Declared purpose and bottom-up use are complementary

Purely bottom-up refinement has a rare-tail failure.

A distinction may matter only once in a thousand tasks but be catastrophic when
it does. Historical task frequency cannot guarantee that the distinction is
safe to discard.

Declared purpose fails in the opposite direction: it can proactively protect
important known distinctions, but cannot anticipate every future purpose.

The likely combination is:

```text
observed work
      +
frontier-agent anticipation
      +
human / institutional wisdom
      ↓
purpose / discrimination boundary
      ↓
World
```

### H4 — human wisdom may mainly provide priors over importance

As models become more capable, the highest-value human contribution may shift
away from prescribing implementation or ontology structure and toward
statements such as:

- these concepts must not be conflated;
- this rare distinction has regulatory importance;
- this exception is intentional;
- this boundary exists for a reason;
- this risk matters even though historical frequency is low;
- we do not have enough evidence to make that conclusion.

The agent performs semantic engineering. The human supplies stakes, horizon,
values, institutional plans, and rare-tail knowledge that cannot be inferred
from repository history alone.

Smaller models may require more explicit human guidance; frontier models may
infer more of the discrimination boundary themselves. Both should use the same
semantic substrate.

## 7. A World may transfer something adjacent to expertise

The strongest long-term value hypothesis is not "structured data is easier to
query."

It is:

> **Persistent semantic abstractions may improve the problem representation
> from which a fresh agent reasons.**

A World can preserve organization-specific distinctions such as:

```text
these identifiers are equivalent for this purpose
these apparently similar concepts are not equivalent
this responsibility belongs to this boundary
this exception overrides the normal rule
this absence does not license a negative conclusion
this relation is incomplete over this scope
this identity remains unresolved
```

This may function as an externalized attentional or conceptual prior.

### H5 — semantic experience transfer

A fresh instance of the same model, given a World accumulated from prior work,
may behave more like an experienced practitioner on structurally novel tasks:

- notice consequential distinctions earlier;
- ask better questions;
- avoid category errors;
- seek better evidence;
- anticipate second-order effects;
- avoid unsupported commitments;
- know when the available evidence is insufficient.

This is a stronger hypothesis than retrieval improvement and has not yet been
demonstrated.

## 8. Capability vs cost are two separate value axes

The product may move the capability-cost frontier in at least three ways:

```text
same model + same cost
    → better result

same model + less cost
    → same result

cheaper/smaller model + semantic state
    → result previously requiring a stronger model
```

### Current evidence

Semantic reuse did not automatically reduce tokens in the grain campaign.

Therefore the next foundational research question should not assume that lower
token cost is the primary value.

### H6 — effective-capability gain

For a fixed model and fixed resource budget, accumulated semantic state may
improve task success, calibration, or judgment on tasks where prior semantic
experience matters.

### H7 — later efficiency/substitution gain

After semantics stabilize and repeated computations become durable, the same
semantic state may allow:

- fewer source reads;
- fewer reasoning loops;
- smaller context;
- deterministic reuse;
- smaller/cheaper models for the same outcome.

Capability gain and cost gain should be measured separately.

## 9. Representation-loss frontier

A World is an explicit declarative projection of much richer experience.

Human expertise and an LLM's temporary internal state are both richer than a
World. The useful research question is therefore not whether an ontology can
represent all thought.

It is:

> **What is the smallest explicit representation that, when combined with a
> capable model's latent knowledge, reproduces the task-relevant benefits of
> prior experience?**

A useful failure decomposition follows.

### 9.1 Abstraction loss

The World discarded a distinction needed by the task.

```text
evidence → World
```

**Likely response:** refine the World or use another purpose-relative World.

### 9.2 Experiential / tacit loss

The relevant experience was not primarily declarative semantic knowledge.

Examples:

- episode/history;
- procedure;
- organization-specific causal pattern;
- social knowledge;
- risk salience;
- perceptual pattern.

**Likely response:** perhaps persist another kind of experience. Do not enlarge
the semantic kernel reflexively.

### 9.3 Semantic-decoding loss

The World contains the intended structure, but a consumer reconstructs the
meaning incorrectly.

**Likely response:** improve semantic legibility, purpose visibility, naming,
definitions, grounding access, or deterministic orientation.

### 9.4 Access / attention loss

The right information exists, but the consumer never retrieves or inspects it.

**Likely response:** agent policy, discovery, orientation, or model capability.

### 9.5 Reasoning loss

The consumer has the necessary information and still reasons incorrectly.

**Likely response:** better model/reasoning, not kernel change.

### 9.6 Salience loss

The right relation exists, but the consumer does not recognize when it should
matter.

This is especially important for the "expertise" hypothesis. Experts often do
not merely possess facts; experience changes what becomes salient in a
situation.

**Likely response:** potentially agent policy, episodic experience, learned
conditional relevance, or stronger model capability.

This decomposition should be used before attributing any future failure to
"the ontology."

## 10. Multiple forms of cumulative experience may eventually coexist

This is a conceptual map, not a product roadmap:

```text
SEMANTIC MEMORY
World
what is true / related / unresolved

EPISODIC MEMORY
cases / incidents / decisions
what happened in particular situations

PROCEDURAL MEMORY
programs / workflows / skills
how recurring work is performed

NORMATIVE MEMORY
purposes / invariants / policies
what must be protected

RAW EVIDENCE
authoritative material from which durable abstractions were built
```

Ontology Author currently occupies the **semantic memory / compilation**
position.

Durable computations provide a first example of procedural persistence.

Do not add episodic or normative "memory systems" merely because this map is
conceptually attractive. Let experiments reveal whether the missing
representation actually matters.

## 11. Agent intelligence is the main lifecycle uncertainty

The hardest long-term hypothesis is:

> **Can capable agents recognize when durable semantic abstraction is useful
> without being explicitly asked to construct one?**

This decomposes into:

### Recognition
Did the agent perform semantic work worth preserving?

### Boundary formation
Can it infer a useful, not-overbroad purpose?

### World selection
Can it discover whether an existing World fits the current task?

### Sufficiency judgment
Can it tell whether the World preserves the distinctions needed now?

### Refinement detection
Can it distinguish "World too coarse" from "one-off hard reasoning"?

### Refine vs create
Can it make a reasonable semantic modularization choice?

### Admission
Can it avoid persisting disposable semantic debris?

The working stance is to test these empirically rather than encode rules for
them into Ontology Author.

## 12. Product layering

The long-term system is easier to understand if separated into layers.

### Agent intelligence

```text
observe work
identify consequential distinctions
infer purpose
anticipate reuse
incorporate human wisdom
notice counterexamples
decide persistence
select / judge / refine / create
compile repeated reasoning into software
```

This is the hard intelligence layer.

### Ontology Author

```text
purpose
construction artifacts
referents
relations
grounding
unresolvedness
completeness
derivations
sealed World
rebuild
```

This is the semantic persistence substrate.

### Applications

Examples may include:

- future agent reasoning;
- software architecture/governance;
- impact analysis;
- compliance;
- supply-chain traceability;
- support entitlement;
- semantic invariants;
- deterministic application computations;
- human inspection and audit.

Applications are not necessarily kernel responsibilities.

### Adjacent source/context infrastructure

Evidence acquisition, exhaustive source traversal, revision discovery, and
source-level reconciliation are related but separate problems.

Keep distinct:

```text
evidence closure
semantic closure
operational closure
```

Ontology Author should not automatically expand into a universal context
compiler.

## 13. Near-term product implications

Do not build the long-term lifecycle yet.

The plausible near-term product work is narrow.

### 13.1 World legibility

A fresh capable agent should cheaply understand:

- what the World is for;
- which semantic relations exist;
- what is unresolved;
- what completeness claims mean;
- how grounding and derivations are exposed.

The deterministic World-context experiment suggests that compact structural
orientation can help without modifying the kernel.

### 13.2 World discovery

Eventually an agent may need a cheap deterministic answer to:

```text
what Worlds exist here?
what purpose does each serve?
```

Discovery should be purpose-oriented, not merely entity-overlap-oriented.

### 13.3 Revision continuity

A later World rebuilt for the same purpose should be intelligible as a
continuation of that semantic abstraction without making sealed Worlds mutable.

These are product affordances, not an autonomous lifecycle engine.

## 14. Experimental sequence

### Phase 0 — foundations

Current task.

- record the design foundations;
- keep the kernel small;
- make the current substrate reliable and legible.

### Phase 1 — semantic experience transfer

This should be the next major value experiment.

Use the same model on genuinely novel tasks under controlled resources.

Candidate conditions:

```text
A — evidence/workspace only

B — evidence + prose memory/summary of previous experience

C — evidence + purpose-relative World
```

The prior experience must not contain the future answers.

Future tasks should be **structural analogues** where a distinction learned
earlier unexpectedly matters.

Measure:

- final task correctness;
- severe conceptual errors;
- unsupported assumptions;
- evidence sought before action;
- time/actions to governing distinction;
- category errors;
- architectural/semantic invariant violations;
- counterfactual consequences anticipated;
- appropriate unresolvedness/escalation;
- transfer across changed surface form.

Primary question:

> **Does a World transfer something more like accumulated semantic expertise
> than ordinary prose memory or fresh raw reasoning?**

### Phase 2 — existing World discovery and use

Give ordinary tasks with a relevant World already present.

Measure whether the agent:

- discovers it;
- uses it;
- understands the purpose boundary;
- knows when raw fallback is appropriate;
- avoids treating the World as authoritative reality outside its scope.

### Phase 3 — bottom-up refinement

Give a task exposing a distinction absent from the World but clearly inside its
existing purpose.

Measure whether the agent:

- notices insufficiency;
- identifies the lost distinction;
- grounds the refinement;
- revises construction;
- rebuilds successfully;
- avoids irrelevant ontology expansion.

### Phase 4 — purpose boundary / semantic modularity

Give a task involving the same source reality but a materially different
observational purpose.

Measure whether the agent makes a reasonable refine-vs-create choice and,
more importantly, whether either choice remains semantically sound and
manageable.

Do not require a single canonical factoring.

### Phase 5 — autonomous persistence

Only after the previous stages work, allow ordinary agents to decide when
semantic work deserves a World.

Measure:

- useful Worlds created;
- unnecessary Worlds;
- duplicates;
- overly broad Worlds;
- later reuse;
- missed opportunities to persist valuable semantics.

### Phase 6 — representation-loss frontier

Compare representations of the same accumulated experience:

```text
RAW EXPERIENCE
PROSE MEMORY
SEMANTIC WORLD
WORLD + SELECTED EPISODES
WORLD + PROCEDURES
FULL WITH RAW FALLBACK
```

Use fresh models on novel analogical tasks.

Goal:

> determine which task-relevant benefits of experience survive explicit
> semantic projection and which require other forms of persistence.

### Phase 7 — capability/cost frontier

Run a matrix such as:

| | smaller model | frontier model |
|---|---:|---:|
| raw workspace | A | B |
| workspace + World | C | D |

Questions:

- **D > B?** Same-model effective-capability gain.
- **C ≈ B?** Semantic state substitutes for model capability/cost.
- Do any conditions dominate on quality per unit cost?

This should happen only after the underlying semantic-experience effect is
established.

## 15. What not to build yet

Do not infer product requirements from the long-term vision prematurely.

In particular, do not add yet:

- a global enterprise ontology;
- global World-level identity reconciliation;
- candidate/durable World lifecycle states;
- an automatic World-creation policy;
- a universal purpose classifier;
- a lifecycle rulebook for weaker models;
- a general context compiler;
- episodic-memory infrastructure;
- agent salience machinery;
- autonomous semantic merging;
- a requirement that agents consume only the World;
- kernel primitives motivated only by ergonomics.

A frontier agent should remain free to use files, shell, Python, SQLite, raw
evidence, and ordinary reasoning.

## 16. Decision rules for future work

### Kernel rule

> Change the kernel only when a concrete correctness requirement cannot be
> represented honestly with current primitives.

### Product rule

> Add product machinery when it materially improves the durable semantic
> substrate or makes that substrate materially more legible/reusable.

### Agent-workflow rule

> If a behavior is primarily a judgment about when, why, or whether to persist
> semantics, keep it in the capable-agent workflow until experiments prove that
> product machinery is necessary.

### Research rule

> Let observed failure identify the next missing representation or capability.

### Architecture rule

> Do not encode the limitations of today's weaker models into permanent
> workflow constraints.

> **Can intelligent work leave behind semantic structure that makes future

Ontology Author is the substrate that makes this question experimentally
testable without requiring the semantic kernel itself to become the
