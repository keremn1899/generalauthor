# Methods integration notes (internal)

These notes are local working comments. They are not a gold ontology.

CLEAR-HTN: the registry primary "change in systolic pressure at 12 weeks" is the same measurement as the paper's "12-week SBP change from baseline". SBP is the abbreviation used in the analysis dataset (`sbp_delta_12`, mmHg).

AURORA: the registered and published primary is glycated haemoglobin / HbA1c at 26 weeks. The deposited core file contains fasting plasma glucose, weight, and visit week. The HbA1c assay file was not transferred with the core deposit.

NORTHWIND: two programmes used the NORTHWIND name. REG-2020-0771 is a 24-week randomised budesonide trial (PI Okonkwo). REG-2018-3301 is a 24-month observational inhaler-utilisation cohort (PI Hale). Publication PUB-NW-2023 and dataset DS-NW-PULM share local protocol code NW-PULM-24 and n=148, and list investigators from both programmes. Methods has not uniquely bound that publication or dataset to REG-2020-0771 versus REG-2018-3301. Shared programme branding is not identity.

HELIOS: the registered primary endpoint is change in Pittsburgh Sleep Quality Index at 8 weeks. The HELIOS paper reports sleep-diary latency as its primary analysis and states that PSQI was analysed as secondary. That is not a wording variant of PSQI.

MARLIN: PUB-MARLIN-2023 is the randomised trial report for REG-2021-2204. The 2022 "Marlin lipid clinic audit" is a retrospective quality report from the same clinic and is not the MARLIN trial.

PINE: only the screening log was deposited. The randomised 4-week total nasal symptom score file has not been released.
