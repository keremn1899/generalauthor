# Frozen semantic principles (participant-visible)

The semantic calculus is frozen. Do not add a new primitive.

```text
REFERENT thin; carries no properties
NAMED TYPED N-ARY RELATION roles are named and typed
DERIVATION maintained, per-relation
```

Grounding, origin, and an explicit unresolved state exist as machinery around those primitives.

World vs purpose: if the current purpose disappeared, would the proposition still have the same meaning? If interpretation depends on the current analytical question, keep it as a purpose requirement.

Do not invent closed-world negation from absence. A missing positive assertion is not a denial.

Minimum sufficient reusable semantics. Do not model the whole commercial universe.

Unresolved semantic demand is what the compiler emits when an authored requirement cannot be satisfied. Do not write trigger instances yourself.
