Harbor towing — service conditions (excerpt, June 2024)

1. Named rate_card rates apply by service except as qualified below.

2. Overtime. For a single vessel, billed hours beyond eight (8) in one local calendar day are charged at one and one-half (1.5) times the applicable hourly rate for those extra hours only.

3. Standby. Code STBY is billed at fifty percent (50%) of the rate_card rate for STBY.

4. Assist. Code ASST is a legacy assist/escort dispatch code. Bill ASST jobs using the ESCORT rate_card row, not the ASST row. The ASST row is retained for historical imports and is not the billing rate.

5. Blank billed_hours. If billed_hours is blank, clock time between start and end is not an established billable quantity. Do not treat blank as zero.

6. Fuel. Fuel surcharges, if any, are published in a separate circular. This excerpt does not contain a fuel schedule.
